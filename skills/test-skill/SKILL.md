# Test Skill

This is a simple skill used for integration testing the skill recognition pipeline.

## Purpose

This skill verifies that:
- Skills are discovered from the skills/ directory
- YAML frontmatter is correctly parsed
- Skills are properly registered in the SkillRegistry
- Metadata is accessible via the registry

## Usage

This skill is not meant for actual use, only for testing the skill system.
